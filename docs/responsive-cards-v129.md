# v129 식당·메뉴 카드 반응형 배치

- 최신 v128 위에 반영했으며 이전 버전을 덮어쓰지 않고 v129로 배포합니다.
- 768px 이상: 식당·메뉴 카드 모두 고정 3열, 간격 12px. 767px 이하: 1열.
- 결과가 1~2개여도 3개일 때의 열 폭을 유지하고 왼쪽부터 배치합니다.
- 식당 카드: 이름 최대 2줄 / 음식·지역 칩 / 주소 최대 2줄 / 하단 비교 아이콘 버튼. 주소를 반복하는 이유 줄은 추가하지 않습니다.
- 행 높이와 하단 비교 위치를 맞추고 이름·주소의 넘침을 잘라 표시합니다. 전체 카드 영역은 기존 상세보기 링크를 확장해 클릭 가능하며 비교 버튼은 독립 동작합니다.
- 본문 최대 폭 720px는 유지합니다. 검색/분류/AI 정책과 데이터 소스는 변경하지 않았습니다.

## 변경 파일

1. `dist/index.html`: 반응형 grid, 카드 높이·말줄임·전체 카드 상세보기 클릭 영역.
2. `scripts/conversation-ui-smoke.mjs`: 5개 폭, 1~2개 결과 폭 유지, 높이 규칙, 클릭 영역 회귀 테스트.
3. `scripts/responsive-card-browser.mjs`: 실제 로컬 Chrome 렌더 계측. 원본 CSS와 실제 식당 카드 렌더 함수를 사용하며 외부 검색/AI 요청 없이 긴 이름·주소 목 데이터를 검사합니다.
4. `docs/responsive-cards-v129.md`: 작업 및 테스트 보고.
