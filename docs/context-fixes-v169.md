# 실제 30발화 평가 후 보완

## 조건 이해와 실행

모델의 intent를 키워드 분기로 대체하지 않았다. 구조화 출력에서 모든 조건 키를 검토하고, 변경하는 값마다 같은 대화의 사용자 원문 근거를 제출하도록 했다. 질문할 때도 이미 이해한 음식·방문 시간을 저장한다. 반경은 사용자 근거에 단위가 없으면 임의의 1km를 명시 조건으로 채택하지 않는다. 기본 반경과 명시 조건을 분리한다.

모델이 스스로 붙인 confidence 하나로 유효한 계획 전체를 거부하던 0.6 임계값을 제거했다. 범위·형식·실제 대상 ID·인용 근거 검사는 유지한다. 불명확함은 별도 clarificationReason으로 표현한다. recommendation/change_conditions이고 실제 필수 입력이 준비되면 검색으로 실행하며, 위치가 없으면 위치, 반경 미확정이면 반경을 질문한다. 음식·동행·시간은 필수 질문 단계가 아니다. 예산 금액 확인과 모호한 해제 대상 확인은 그 항목 하나만 묻는다.

visit/visitAt(방문 맥락/시각)과 requireOpen(필수 영업 조건)을 분리해 전달하고, 방문 맥락 수정 시 오래된 구체 시각을 제거한다. 확인된 영업 일정의 적용 기간이 없으면 현재 영업 중이라고 단정하지 않는다.

## 동의와 사실 정보

명시적 미확인 표시 동의는 원문 근거를 확인한 뒤 독립 실행 경로로 정규화한다. 모델이 answer로 분류했더라도 동의가 있다는 이유로 예외 처리하지 않는다. 수락한 항목은 위치·거리 변경으로 초기화하지 않으며, 해당 미확인 기준 자체가 달라지면 재확인한다. 이 값은 가격·혼밥 등 조건을 충족한다는 증거가 아니다.

서버가 실제 데이터로 작성한 비교·상세 정보·미확인 설명에는 copySource=program을 부여했다. 식당명·메뉴 이름의 일부가 금지어 또는 음슴체 종결처럼 보인다는 이유로 사실 본문 전체를 일반 추천 문장으로 덮지 않는다. 모델 작성 질문의 말투 검사와 비공개 분석 필드 제거는 유지한다. 프로그램이 기록하는 진단에는 행동·수정 슬롯명·오류 코드만 포함하며 키/헤더/모델 원문/사용자 원문을 넣지 않는다.

## 0건 경로

현재 실제 등록 원본을 확인한 결과 성동구 5곳에 파스타 명시 메뉴는 0건, 마포구에 삼겹살 명시 메뉴는 0건이었다. 예전 외부 검색 시의 성수 파스타 결과와 현재 등록 전용 검색은 데이터 범위가 다르다. 이 결과를 만들려고 외부 식당을 추가하지 않는다.

등록 메뉴와 지역으로 검색 풀을 구성한 다음, 기존 8개 일괄 조회 대신 최대 24개를 4개씩 확인한다. 실제 거리·예산·메뉴 검사를 통과한 결과가 충분해지면 멈춘다. 좌석/주차 등 원본에 없는 근거를 얻기 위해 모든 후보를 불필요하게 조회하지 않는다. 다른 곳 재추천에서는 이전 식당을 제외한 수를 기준으로 다음 묶음을 확인한다. 24개 상한 밖의 모든 식당 좌표를 전수 조회하는 기능은 아니다.

국밥/순대국/곰탕, 파스타/스파게티 등 검색 개념은 등록된 메뉴 텍스트와 대조하며, 삼겹살에 양갈비를 섞는 식의 자동 완화는 하지 않는다. 예산 판단에도 같은 메뉴 매칭을 쓴다. 데이터 없음은 등록 메뉴 범위라고 안내한다.

searchDiagnostics: registeredTotal, menuRegionCandidates, lookedUp, identityMatched, outsideRadius, withinRadius, candidateLimit, truncated를 기록해 0건이 발생한 단계를 구분한다. 좌표와 개인 위치 원문은 기록하지 않는다.

## 검증 범위

build-worker와 policy-smoke에 다음 회귀를 추가했다: 질문과 동시에 음식 저장, 조건 준비 후 진행, 기본/명시 반경 분리, 동의 answer 정규화 및 거리 변경 유지, 날짜 맥락과 필수 영업 구분, 비교 사실 본문 보존, 메뉴 개념 불일치 제외, 첫 8개 밖에서 실제 통과 식당을 찾는 진행형 검색. 기존 실제 1,099곳 연결·플레이스 링크·UI 회귀도 유지한다. 테스트 fixture는 배포 등록 데이터에 포함하지 않는다.

실제 서비스 30발화 재검증 결과는 별도 QA 보고서로 제공한다. 모킹 통과를 실제 모델의 의도 정확도나 실기기 동작 완료로 간주하지 않는다. 실제 기기 위치 권한, 모바일 지도 앱/웹 복귀, 모든 등록 식당 좌표의 전수 실사는 이번 코드 회귀 테스트에 포함되지 않는다.
