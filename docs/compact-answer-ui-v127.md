# v127 답변 인터페이스 정리

## 적용 기준

요청의 진단 문구와 구체적인 C/E 배치가 일부 달라, 구체적인 수정 규칙을 우선했다. 복사·재생성은 질문/답변 칩 다음, 연관 질문 앞에 두고, 맨 아래로 버튼은 입력창 위 오른쪽에 배치했다. 의도 분류·검색·추천·슬롯 정책은 변경하지 않았다.

## UI 변경

### 식당 카드

- 패딩 14px, 카드 간격 10px, 높이/상한 110px로 축소했다.
- 식당명과 오른쪽 chevron이 있는 헤더 줄 전체가 상세보기 링크/버튼이다. 별도의 큰 상세보기 버튼은 제거했다. 기존 정확한 매장 링크와 매장 확인 재시도 기능은 유지한다.
- 음식 종류·지역 칩 한 줄, 주소 한 줄(말줄임)로 구성했다. 주소 전체는 title 속성으로 남긴다.
- 우하단 비교 버튼은 작은 12px 라벨과 compare-add 아이콘이며 터치 영역은 40px이다. 담으면 check + `담음`, 다시 누르면 해제한다. 접근성 이름에는 식당명과 행동을 함께 넣었다.
- 추천 이유 줄은 컴팩트 카드에서 그리지 않는다. DB imageUrl이 있는 경우의 선택적 썸네일은 40px로 유지한다. 외부 이미지는 수집하지 않는다.

### 대화 본문·하단

- AI 응답 첫 줄 옆에 24px 브랜드 로고를 복원했다. 본문은 말풍선 없이 왼쪽 정렬한다.
- 순서는 본문 → 카드 → 카드 묶음 아래 출처 → 질문/답변 칩 → 복사·재생성 → 연관 질문 → 행동 칩이다.
- 답변 도구는 20px 아이콘, 40px 터치 영역, #666이다. 복사 성공 시 1.5초간 check로 바뀌고 다시 copy로 돌아온다.
- 같은 지역/음식 조건 칩은 직전 AI 응답과 같으면 생략한다. 다른 축으로 바뀌거나 다른 응답을 거치면 다시 표시한다. 저장된 대화 재생과 마지막 응답 재생성에서도 순서를 기준으로 판단한다.
- 답변 칩은 검정 테두리+흰 배경, 행동 칩은 회색 테두리+작은 글자, 연관 질문은 연회색 채움 행으로 구분한다.

### 아이콘·맨 아래로

- 제공된 24종 symbol을 index.html body 상단에 인라인 삽입했다. use 참조와 currentColor/선 1.75/round 규칙을 사용한다.
- 전송·정지·더하기·복사·재생성·화살표·메뉴·새 대화·비교·닫기·위치·음식·조건·동행·이력·재시도·검색·업로드·선택 표시를 SVG로 통일했다. 유니코드 아이콘 문자 대신 스프라이트를 사용한다.
- 플러그인 공통 시트 닫기와 선택 체크, 지역/음식 선택기, 재미 도구의 추가·결과 버튼도 같은 아이콘을 쓴다. 사다리 결과의 텍스트 구분자는 콜론으로 바꿨으며 게임 동작은 같다.
- 맨 아래로 버튼은 fixed 입력창 dock 안의 전용 줄에 오른쪽 정렬했다. 버튼 40px, 그 아래 간격 12px이다. 비교 트레이가 있어도 입력창 바로 위에 남는다.
- 버튼을 카드 위에 띄우지 않고 dock 높이에 포함한다. ResizeObserver는 실제 dock 높이를 측정하고 메시지 하단 여백에 반영한다. 따라서 맨 아래로 버튼 표시 여부와 비교 트레이에 따라 공간이 확보된다.

## 검증

`node scripts/build-worker.mjs && node scripts/policy-smoke.mjs`

전체 기존 모킹 회귀에 v127 검사를 추가했다:

- 실제 렌더러의 카드 헤더 상세보기, 큰 상세보기 버튼 부재, 비교 담기/해제·체크 전환
- 본문·카드·출처·질문·답변 칩·액션·연관 질문·행동 칩 순서
- 24px AI 로고, 직전 조건 중복 생략과 축 변경 시 재표시
- 실제 복사 함수의 카드 요약 포함, 1500ms 체크 전환 및 복원
- symbol 24개, 유니코드 아이콘 부재, SVG 버튼 aria-label
- 110px 카드 상한·말줄임·40px 버튼·12px 간격·dock 내부 위치의 DOM/CSS 계약
- 360/390px의 가용 폭과 카드 행 높이 예산 검사
- 기존 v126 추천 행 5개 클릭/직접 입력 → 카드 렌더, 비교 트레이, 메뉴/지역/플러그인/게임 동작
- 인라인 JavaScript 문법 및 diff 공백 검사

인증 실패·504 로그는 실패 처리용 모킹이다. API 키 확인·AI 평가·실제 AI/네이버 호출은 실행하지 않았다.

**실제 브라우저 360~390px 픽셀 렌더·손가락 터치·실제 클립보드 권한 점검은 미완료**다. 카드 높이와 겹침은 DOM/CSS 및 레이아웃 규칙으로 검사했으며 실제 화면 스크린샷 확인으로 표현하지 않는다.
