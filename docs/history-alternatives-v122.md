# v122 카드 이력과 메뉴·지역 대안

## 변경 동작

- 이전 메뉴 카드·식당 카드·칩은 대화에 남기고 다음 사용자 메시지 때 비활성화해요. 선택한 메뉴·질문 칩은 진한 테두리와 체크로 남고, 나머지는 흐려져요. 식당 이름·서수로 선택한 카드도 표시해요. 저장된 대화를 다시 그릴 때 같은 상태를 복원해요.
- 메뉴 제안 아래 `다른 메뉴 보기`를 항상 보여줘요. 선택한 종류를 별도 상태에 유지하고, 같은 종류에서 이전 제안을 제외한 메뉴 세 개를 새 응답으로 보여줘요. 이전 세 개는 이력으로 남아요. 아홉 종류에 최소 여섯 메뉴를 준비해 첫 두 묶음이 겹치지 않아요. 준비한 메뉴가 소진되면 재사용을 새 메뉴인 것처럼 안내하지 않고 다른 종류를 제안해 달라고 안내해요.
- 지역 질문은 현재 위치 연결/강남/홍대/역삼/성수/직접 입력 여섯 칩만 사용해요. `상관없어요`는 지역 질문에 없어요. 직접 `아무데나`, `아무 데나`, `어디든`, 지역 질문 뒤 `상관없어요`라고 답하면 강남부터 찾는다고 명시하고 다른 지역 칩도 보여줘요. 인기·수요 근거는 만들어 말하지 않아요.
- 0~2건 검색 응답은 실제 개수와 인접 지역·비슷한 음식 대안 칩을 보여줘요. 국밥에는 설렁탕·곰탕을 제안해요. 대안 칩도 자연어 메시지로 기존 검색 경로를 타요.
- 지역을 맡긴 경우에만 기본 지역 결과가 세 곳 미만이면 인접 지역을 최대 두 번 추가 검색해요. 음식 조건·이전 식당 제외·음식/지역 검사를 유지하고 중복을 제거해요. 확보한 실제 식당만 최대 세 곳 보여주며 카드에는 각 검색 지역을 표시해요. 세 곳을 확보하지 못하면 실제 개수와 대안 칩을 유지해요. 지역을 직접 고르면 자동 확장은 꺼져요.

## 지역 범위

기본 칩은 강남·강남역·역삼·홍대·성수·종로·여의도 그대로예요. 인접 지역 대안이 실제로 동작하도록 논현·합정·상수·뚝섬·서울숲·안국·을지로·영등포·당산도 지역 검사에 허용해요. 이 목록은 도보 거리나 인기 순위가 아니라 주소 영역 기준이에요. 자동 지역은 강남→역삼→논현 순으로 실제 결과가 충분할 때까지만 검색해요.

## 검증

- `node scripts/build-worker.mjs && node scripts/policy-smoke.mjs`: 통과.
- 인라인 프런트 스크립트 구문 검사, `git diff --check`: 통과.
- 실제 렌더러 DOM 모킹: 카드·칩 이력 유지, 선택 체크, 비활성 클릭 차단, 새 칩 활성, 대화 재생 복원, 대안 칩 자연어 전송.
- 아홉 종류별 첫/다음 세 메뉴가 같은 종류이며 겹치지 않음, 소진 시 재활용하지 않음.
- 지역 질문 여섯 칩·상관없어요 부재, 직접 발화 네 형태, 불확실한 분류에 대한 명시적 지역 답변 우선, 음식과 아무데나 동시 입력.
- 0/1/2건 대안, 인접 지역 추가 검색, 음식·지역 불일치 제외, 중복 제거, 확장 실패 시 개수 보존, 지역 변경 시 자동 확장 해제, 다른 식당 검색 뒤 대안 유지.
- 기존 모드/FAQ/비교/문체/슬롯 smoke 전체도 통과.
- 모든 외부 응답은 모킹했어요. 키 파일 확인·실제 AI 평가·실제 검색 API 호출은 하지 않았어요. 실제 브라우저·모바일 렌더 확인은 미실시예요.
