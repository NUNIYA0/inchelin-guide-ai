# v176 위치 선택 UX 정리

- 문제: 시·도/시·군·구를 별도 페이지처럼 넘기고, 전체/지역/역 필터와 경로 버튼·긴 데이터 안내가 동시에 표시되어 목록 공간을 소모했다.
- 시·도 탐색과 세부 지역을 한 화면의 2열로 배치했다. 시·도는 왼쪽 탐색, 지역은 오른쪽 타일이며 매장 수만 짧게 표시한다. 처음 보이는 시·도는 탐색을 위한 표시일 뿐 위치를 자동 확정하지 않는다. 역 선택 전에는 확정 버튼이 비활성이다.
- 중복 필터와 경로 버튼을 제거했다. 역 단계에서는 지역 이름과 지역 바꾸기만 표시한다. 지역 타일의 핀/반복 설명과 역의 반복 종류 배지를 줄였다. 정상 화면의 긴 데이터 정제 설명은 기존 데이터 점검 문서로 유지하며, 선택 창에는 짧은 행동 안내만 보여준다.
- 검색은 지역 단계와 독립적으로 전체 등록 지역/역을 찾는다. 역 이름을 알고 있으면 시·도·구를 먼저 누를 필요가 없다. 역 검색은 이름만 검색하여 음식점이 상위에 나오는 것을 피하도록 지하철역 문맥과 역 이름 질의를 병렬 사용하되 기존 지역/카테고리/좌표 검증을 유지한다.
- PC 중앙 모달과 모바일 바텀시트, 취소/선택하기, 단일 선택, 체크·라디오 장식 제거, 지역 데이터·검색 좌표 검증은 유지한다.
- 실제 PC 및 360px 브라우저 뷰포트에서 지역/역 단계와 스크롤을 확인한다. 실제 모바일 기기 가상 키보드·GPS는 별도 검증 대상이다. AI 호출은 하지 않는다.
