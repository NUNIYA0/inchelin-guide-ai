# v120 대화·카드·비교 사용성 수정

## 변경

- 사용자용 안내 → 카드 → 출처 → 질문 하나 → 답변 칩 → 별도 행동 줄로 읽혀요. 결과 조건 칩은 맨 위에 유지해요.
- 답변 칩은 40px 이상·8px 간격·줄바꿈, 행동 줄은 연한 스타일 최대 두 개(다른 곳도 보여줘/조건 바꾸기)예요. 비교하기·메뉴 탐색 응답 칩은 없어요.
- 새 사용자 메시지가 오면 이전 질문·메뉴·행동 선택지를 숨겨요. 식당 카드의 상세보기·비교에 담기는 계속 쓸 수 있어요.
- 메뉴 카드는 17px/700 제목, 22자 이내 설명, 30자 이내 해요체 이유를 사용해요. 반복 이유·너무 긴 이유는 생략해요. 모바일에서는 한 줄을 넘으면 말줄임하고 접근성 이름에는 설명을 남겨요.
- 상관없어요는 그 슬롯을 건너뛰고 다시 묻지 않아요. 필수 지역/메뉴가 비어 있으면 임의로 채우거나 검색하지 않아요. optional 후속 질문을 받은 직후에는 질문을 쉬어요.
- 비교 트레이는 고정 입력창 위에 있어요. 담기/빼기, 1곳 비활성, 2~3곳 활성, 3곳 제한을 적용해요. 비교 문장은 ‘해정집이랑 옥동식 비교해줘’처럼 일반 입력 경로로 보내요.
- 비교 답변은 음식 종류·지역·주소·주소에 적힌 층만 보여요. 모르는 항목은 한 줄로 안내하고 맛·평점·인기·주차 등을 추측하지 않아요.
- 채팅 내부 스크롤 대신 문서 전체를 스크롤해요. 입력창은 안전영역을 반영해 고정하고, 새 답변은 시작 지점으로 이동해요. 생각하는 중 점은 reduced-motion에서 멈춰요.
- v119 문장 검사·내부 분석 필드 제거는 유지해요.

## 검증

- `node scripts/build-worker.mjs && node scripts/policy-smoke.mjs` 통과.
- DOM 회귀: 골격 순서/출처 1회, 답변·행동 그룹, 메뉴 위계·길이, 숨긴 이전 칩, 비교 담기/빼기/최대 3곳/2곳 활성/자연어 전송, 제거된 중복 버튼, 문서 스크롤·고정 입력창.
- 정책 회귀: 필수/선택 슬롯의 상관없어요, 재질문 방지, 선택 질문 연속 방지, 확인된 항목만 비교, v119 금지 문구·필드 제거.
- 실제 브라우저: 로컬 합성 데이터 화면에서 360×800/390×844 확인. 가로 넘침 없음, 제목 17px·설명 14px·이유 weight 400·답변 칩 40px 확인. 문서 root가 스크롤하고 body와 채팅 박스에는 내부 스크롤이 없음을 확인.
- 실제 브라우저에서 비교 트레이 1/2곳 상태, 자연어 사용자 말풍선 생성, 이전 답변 칩의 display:none 확인.
- 라이브 AI 호출 테스트와 AI 평가는 하지 않았어요. API 키·키 파일·런타임 환경변수를 확인하거나 변경하지 않았어요.
- 브라우저 사진은 로컬 합성 샘플이며 실제 추천 결과/품질 증거가 아니에요. `scripts/preview-conversation-ui.mjs`는 로컬 전용이고 배포 자산에는 들어가지 않아요.
