# v145 실제 1,099곳 연결

## 원본과 배포

- 사용자 제공 `인슐랭가이드 매장_정보확인 1099곳_261026.xlsx`, 시트 `05_정보확인완료_1099곳`, 1099행. SHA256 `81699ec6bfd876d9ae1a9b2a5b6a805c5a4cd4e8642eaf01a41184696135f696`.
- `scripts/import-restaurants.py`는 원본을 읽기만 하며 운영 JSON `data/private/restaurants-261026.json`을 생성한다. 메뉴·가격 원문, 연락처·요일별 영업시간, 수집일, 상호·주소, 추천인을 보존한다. 13014개 메뉴 항목 중 금액이 명시된 경우만 숫자로 옮기고 변동/미상 가격은 null이다. mainDish는 식사 메뉴 사전과 사이드/추가/다인세트 제외 규칙이며, 원문에 없는 인당 가격은 계산하지 않는다.
- 추천 이유, 사진, 좌표, 추천 작성일은 원본에 없으므로 만들지 않는다. 추천 ID는 원본 번호에서 결정적으로 생성한 내부 식별자이며 실제 앱 추천 ID가 아니다. 수집일을 추천 작성일로 쓰지 않는다. 동일 레코드의 추천인에 null 이유가 연결되어 `추천 이유 없음`으로 표시된다.
- 원본과 운영 JSON은 공개 GitHub에 올리지 않는다. Git 추적 제외된 파일은 빌드 입력으로만 쓰며 Worker 안에 서버 측 스냅샷으로 포함한다. 전체 DB를 반환하는 API/브라우저 자산은 없다. 카드에 선정된 기록만 반환한다. 배포 아카이브는 포함하지만 공개 GitHub 코드만 내려받아서는 원본 없이 빌드되지 않는다.
- 운영자는 원본 제공 후 `python scripts/import-restaurants.py <xlsx 경로> data/private/restaurants-261026.json`을 실행하고 `node scripts/build-worker.mjs`를 실행한다. 공개 코드에 원본 JSON을 강제로 추가하지 않는다. 다음 데이터 교체 시 원본 해시·행 수를 갱신하고 검증한다.

## 검색

- exclusive=true: 등록 목록 안에서만 추천. 외부 식당으로 숫자를 채우지 않는다. 네이버는 등록 매장의 좌표·업종 확인에만 사용한다.
- 원본에 좌표가 없어 서울 역별 구/군 주소와 명시 메뉴로 등록 후보를 찾는다. 한 번에 최대 8개의 등록 매장을 병렬 조회한다. 상호(원본 별칭 포함)+도로명 건물번호+구/군이 일치하거나 동일 네이버 place ID일 때만 좌표를 수용한다. 실제 기준점과 직선거리를 계산해 요청 범위 밖은 제외한다. 좌표/매장 일치를 못 확인한 곳은 지어낸 좌표로 추천하지 않는다.
- 1시간 메모리 좌표 캐시를 사용한다. 매 요청에서 반경·조건은 다시 판정한다. 8개 조회 제한 때문에 등록 목록 전체의 완전한 최근접 탐색을 보장하지 않는다. 등록됐어도 좌표 미확인·조회 제한으로 이번 결과에 안 나올 수 있다. 전체 좌표 정제/색인은 후속 과제다.
- 7개 역과 현재 위치의 기존 위치 흐름은 유지한다. 현재 위치 후보는 가장 가까운 지원 역의 구/군으로 좁힌 뒤 실제 좌표로 필터링한다. 전국 임의 지역을 모두 지원한다고 안내하지 않는다.
- 메뉴·가격은 수집일 스냅샷이다. 요일/휴무/브레이크타임을 포함한 원문은 상세 질문에 제공하지만 현시점 영업 여부를 보장하지 않는다. `영업 중인 곳만`은 미확인 표시 동의를 요청하며 임의로 충족 처리하지 않는다. 주차·좌석·혼밥 근거는 별도 데이터가 없어 미확인으로 유지한다.

## 검증 구분

- 빌드·policy-smoke는 원본 1099행을 실제로 읽는다. 원문 추천인/메뉴/가격/영업시간/연락처의 정확한 연결과 원본 해시를 검사한다. 좌표/네이버 응답은 모킹이므로 이를 1099곳 전체의 실제 좌표 검증으로 보고하지 않는다.
- 기존 외부 검색 회귀는 데이터 비연결 상태의 테스트 전용 Worker 복사본으로 계속 실행한다. 실제 운영 Worker는 별도로 등록 전용 검색 테스트를 한다. 테스트용 가상 작성자는 배포 Worker에 포함되지 않는지 검사한다.
- 배포 후 실제 네이버 응답으로 확인한 화면과 결과는 완료 보고에서 구분한다. 실제 모바일 GPS/지도 앱 왕복, 원본 1099곳 전체 좌표 검증과 전 메뉴 가격의 현재성은 별도 미검증이다.
