# v125 연관 질문과 대화 인터페이스

## 동작

- 연관 질문의 지역은 강남·강남역·역삼·홍대·성수·종로·여의도만 허용한다. 별칭은 기존 정규화 사전을 사용한다.
- 지역×음식 검색 제안은 기존 후보 검사를 그대로 거친 결과가 1개 이상 있을 때만 노출한다. 현재 응답의 검증 결과를 먼저 재사용하고, 없으면 최대 3회 사전 조회한다. 이 조회는 현재 카드 목록을 바꾸지 않는다.
- 네이버 사전 조회는 첫 쿼리 1회/650ms, 전체 확인은 700ms 제한이다. 시간초과·오류·0건은 해당 제안을 버린다. 최대 150개 메모리 캐시를 사용하며 성공 3분, 실패 15초 보관한다. 키·좌표·사용자 대화는 캐시에 저장하지 않는다. 워커 인스턴스가 바뀌면 캐시는 초기화된다.
- 부탁형 `~해주세요/~찾아주세요`를 거르고 사용자 발화형 `찾아줘/보여줘/어때?`를 사용한다. 메뉴 더 보기·다른 곳 보기 칩과 같은 기능의 제안은 제외한다. 남은 안전한 제안이 부족하면 억지로 채우지 않는다.
- 지역·위치·상세보기 FAQ에 사용자 발화형 예문을 추가했다. FAQ 답변은 계속 고정 JSON을 사용한다.

## 대화 UI

- AI는 아바타/말풍선 없이 왼쪽 본문, 사용자는 오른쪽 최대 80% 회색 말풍선이다. 본문 16px/1.6, 메시지 간격 24px, 데스크톱 읽기 열 최대 720px이다.
- 새 AI 응답 블록은 짧게 순차 등장한다. 실제 네트워크 SSE 스트리밍은 아니며, reduced-motion에서는 즉시 표시한다. 로딩 점은 하나다.
- 답변 아래 복사/다시 생성 아이콘이 있다. 복사는 답변+메뉴/식당 카드 요약을 포함한다. 재생성은 마지막 AI 응답만 교체하고 기존 사용자 메시지를 다시 만들지 않는다. 과거 응답에서는 재생성을 실행하지 않는다.
- 생성 중 입력은 가능하며 전송 버튼은 정지 버튼이다. 재생성 정지는 원래 답변을 유지한다. 취소된 이전 요청이 새 요청의 생성 상태를 지우지 않는다.
- 입력창은 하단 고정 알약형이고 최소 52px, 5줄까지 확장한다. 데스크톱 Enter 전송/Shift+Enter 줄바꿈, 모바일·터치 입력은 Enter 줄바꿈/전송 버튼을 사용한다.
- 새 응답의 시작으로 이동하지만 위로 스크롤해 읽는 중이면 강제로 이동하지 않는다. 이때 맨 아래로 원형 버튼을 제공한다.
- 입력창 위 상시 플러그인 칩을 제거했다. 핀 상태는 플러그인 패널에만 남는다. 비교 트레이와 종류/지역/메뉴/식당 카드·연관 질문 구조는 유지한다.

## 테스트

`node scripts/build-worker.mjs && node scripts/policy-smoke.mjs`

전체 회귀와 v125 모킹 검사를 실행했다. 모든 fetch는 테스트 응답으로 대체하며 실제 AI/네이버 호출이나 API 키 파일 확인을 하지 않는다. 인증 실패·504 로그는 실패 처리 검사용 모킹이다.

- 지원 밖 지역, 검색 0건, 시간초과, 예외, 캐시 재사용, 칩 의미 중복 및 부탁형 차단
- 실제 렌더러의 답변 도구·AI 아바타 부재와 기존 카드/이력 유지
- 실제 함수의 클립보드 내용·재생성 요청/응답 교체·정지·입력창 확장·위로 읽을 때 스크롤 차단
- 360/390px DOM/CSS 계약: 3열 질문 화면, 카드 폭, 사용자 80%, 입력창/본문 규격, reduced-motion

실제 브라우저 픽셀 렌더·모바일 키보드·실제 클립보드 권한·라이브 검색 결과 확인은 **미완료**다. 사용자 요청에 따라 빌드·모킹 smoke·배포만 수행한다.
