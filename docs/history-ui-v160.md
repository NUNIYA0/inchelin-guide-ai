# v160 대화 관리 UI

- 대화 이력은 기존 브라우저 localStorage의 `insight-ai-history`를 그대로 사용한다. 서버 동기화나 새로운 데이터 연결을 추가하지 않았다.
- PC의 기본 포인터가 마우스면 행 호버·포커스·메뉴 열림 상태에서만 ⋯를 노출한다. 보조 터치 장치가 있다는 이유만으로 항상 표시하던 조건은 제거했다. 기본 터치 환경 또는 실제 터치 입력 후에는 항상 노출하며, 다시 마우스를 쓰면 PC 규칙으로 돌아간다. 제목 공간과 44px 터치 영역은 고정이다.
- 메뉴는 버튼 근처에 열리고 뷰포트 가장자리 안으로 보정한다. 이름 변경/삭제만 제공하며 선 아이콘·삭제 빨강·호버/포커스 스타일을 적용한다. 다른 메뉴 열기·바깥 클릭·Esc로 닫고 키보드 방향키/Home/End를 지원한다.
- 이름 변경은 행 안의 입력창에서 기존 제목을 전체 선택한다. Enter 저장, Esc/blur 취소, IME 조합 Enter 무시, 빈 이름 저장 금지, 기존 40자 제한을 유지한다.
- 삭제는 기존 native dialog 기반 프로젝트 스타일을 재사용한다. 화면 전체 중앙 모달, 배경 차단, 취소 초기 포커스, Tab 순환, Esc 취소, 포커스 복원을 지원한다. 삭제는 복구 기능이 없는 브라우저 로컬 기록 삭제임을 안내한다.
- 이름 변경/삭제는 새 목록을 먼저 저장한 뒤 메모리와 화면에 반영한다. 실패 시 이전 목록·제목을 유지한다. 삭제 실패는 모달 안에 표시하고 재시도를 허용한다. 실행 중 버튼을 잠그며 현재 대화 삭제 후에는 기존 newChat 흐름으로 이동한다.

## 확인

- build-worker, policy-smoke 통과. 저장 실패·빈 제목·IME 조합 Enter·blur 취소·삭제 오류/중복 방지·포커스 콜백은 테스트 전용 메모리 DOM/저장소로 검증한다.
- 로컬 브라우저 PC 1280px: 실제 마우스로 행 사이 빈 공간에 포인터를 올려 해당 행만 버튼 표시, 메뉴 열린 동안 표시 유지, 키보드 포커스, 이름 전체 선택·Enter 저장·Esc/blur 취소, 메뉴 전환·바깥 클릭·삭제 취소/Esc/확정, 현재 테스트 대화 삭제 후 새 대화 이동 확인.
- 모바일 390px 브라우저 뷰포트: 메뉴·모달 열기/취소, 화면 내 위치, 가로 넘침 없음 확인. 실제 모바일 기기의 터치·가상 키보드/IME는 미검증이다. 정상 검색이나 AI를 호출하지 않고 로컬 QA 응답을 사용했다.
- 실제 식당 데이터, 검색·위치·지도 기능은 변경하지 않았다.
