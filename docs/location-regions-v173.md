# v173 등록 맛집 기준 지역 → 지하철역 선택

- 지역 목록은 제공된 1,099곳의 주소에서 빌드 시 생성한다. 원본 주소를 보존하여 광주와 전남을 분리한다. 17개 시·도 / 182개 시·군·구 그룹, 지역 분류 완료 1,091곳.
- 원본부터 `전남광주`로 합쳐진 주소 8곳은 어느 시·도로도 임의 배정하지 않는다. 목록의 매장 수에서 제외하고 선택 창에 건수를 고지한다. 검색 데이터 자체는 삭제하지 않는다. 원본 정정이 필요하다.
- 시·도 → 시·군·구 → 해당 지역의 역 순서다. 역 이름 직접 검색도 유지한다. 숫자는 등록 주소 기준 매장 수이며, 역 반경 안의 추천 수나 역 전체 개수가 아니다.
- 역 정보는 원본 맛집 파일에 없다. 기존 네이버 지역 검색 서버 연결로 지하철/전철 카테고리, 실제 주소의 시·도·시·군·구, 좌표를 확인하여 노출한다. 다른 지역·출입구·음식점·좌표 없는 항목은 제외한다. 서버 키는 브라우저로 전달하지 않는다.
- 검색 API의 조회 수 제한 때문에 완전한 전국 역 목록은 아니다. 두 개 지역 검색을 병렬 실행하고 중복 제거·1시간 캐시한다. 확인된 역이 없으면 빈 결과와 역 직접 검색/지역 변경 안내를 표시한다. 확인되지 않은 역이나 지역 중심 좌표는 생성하지 않는다.
- 선택한 역은 서버에서 다시 확인하며 regionId·이름·좌표로 기존 추천 흐름에 연결한다. 반경 답변·거리 변경 뒤에도 regionId를 유지하고, 동명이거나 같은 구 이름인 다른 시·도 매장은 지역별 후보 단계에서 제외한다.
- PC 중앙 모달, 모바일 바텀시트, 선택 배경/테두리, 체크·라디오 장식 없음, 취소/닫기/포커스 복원은 유지한다.

## 검증
build-worker / policy-smoke: 실제 1,099곳 그룹 합계·원본 누락 8건·광주/전남 분리, 모의 역 검색의 카테고리/지역/좌표 검증, UI의 서울→강남구→역삼역→확정, 동일 지역 후보 필터, 기존 대화/위치/지도 회귀. AI 실제 평가나 키 파일 조회는 하지 않는다.
